# Runtime Operations Contract

## Purpose

Define local review, batch, retry, run-index, distribution, and export behavior for M16-M20.

## Applies To

- `scripts/review_run.py`
- `scripts/batch_runner.py`
- `scripts/run_database.py`
- `scripts/plugin_package.py`
- `scripts/export_run.py`
- Helpers under `scripts/inward_eyes/`

## General Rules

- `manifest.json` remains the source of truth for a run.
- Run indexes, review files, package manifests, and exports are derived views unless explicitly listed in a run manifest.
- Derived views must not mutate canonical claim, price, page, source, or capture artifacts silently.
- Runtime outputs belong in the user's output root or ignored eval output, not inside the installed plugin package.
- Do not store cookies, tokens, HAR logs, browser profiles, local storage, session storage, passwords, payment data, or unrelated account data.
- Do not execute code from run artifacts or webpage content.

## Review UI

The v1 review surface is a CLI/text UI.

It may summarize:

- Run status and validation status.
- Manual-review reasons.
- Completion blockers and warnings.
- Missing manifest paths.
- Artifact and evidence paths.

It must not silently approve, reject, or rewrite canonical artifacts. Future decision records must be separate artifacts.

## Batch and Retry

Batch execution is sequential by default.

Rules:

- Each batch item creates its own run directory.
- Retries create new run directories and never overwrite prior attempts.
- Child `manifest.json` status is the semantic source of truth; process exit code is secondary.
- Do not auto-retry `aborted_by_policy`, private-data blockers, scope blockers, or manual-review partials.
- Logs should retain minimal operational metadata and avoid full stdout/stderr capture by default.

## Run Index

The run index is a rebuildable JSONL view generated by scanning run manifests.

Rules:

- Rebuilding an index must not modify source runs.
- Stale indexes are advisory only.
- Retry plans are derived from index records and must still be reviewed before execution.

## Distribution

M17 implements local package dry-run behavior only.

Rules:

- Local packages must exclude `.git`, `browser-operator-runs/`, `evals/.tmp/`, `dist/`, `__pycache__/`, and cache output.
- Package validation must keep plugin capabilities read-only.
- Marketplace publication, marketplace metadata, and release tagging are out of scope unless explicitly approved.

## Exporters

Exporters are view-only.

Rules:

- Exporters read canonical run JSON and source records.
- Exporters may write JSON, CSV, and Markdown summaries.
- Exporters must not alter canonical artifacts.
- Exporters must not introduce non-standard-library dependencies without approval.

## Validation

Release gates must run:

```powershell
python evals\run_review_ui_eval.py
python evals\run_distribution_eval.py
python evals\run_batch_retry_eval.py
python evals\run_export_eval.py
```
